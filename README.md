# ningen-slides

> すぐ使う：このリポジトリのURLをClaude（またはMuse）に渡して「スキルを使えるようにして」と言うだけ。

AIが作るスライドにありがちな「AIっぽさ」を消すためのClaude向けスキル、natural-slides の強化版です。土台の制作ルール（図と太い線と言い切る文で、人が作ったような資料にする）に、仕上げの自己点検リストを組み込みました。

## 土台との違い

- 制作ルール本体は natural-slides（yoshitakagiii、MIT）をそのまま引き継いでいます
- 追加したのは2点だけです
  1. 「仕上げのNG点検」の節：出す前に1枚ずつ見直す点検項目（文字加工・線と飾り・色と構成の3分類）
  2. 最終チェックへの3項目の追加（24の点検、色帯と飾り線、構図の使い回し）
- 点検項目の一部は KAWAI（@kawai_design）の図解を参考に、スライド制作の点検用に再構成しました

## 仕上げのNG点検（要約）

- 文字加工・組み方：フチ文字／ドロップシャドウ／光彩・グロー／立体文字・ベベル／長体・平体／斜体・文字の傾き／単語の途中で改行／読めない小さい文字
- 線・カード・飾り：区切り線の多用／囲み線の多用／装飾的な下線／カード上部の色帯／カード左側の色帯／ちょんちょん・放射線／意味のないアイコン／角丸カードの乱用
- 色・余白・構成：目的のないグラデ／ノイズ・紙の質感／強調色の使いすぎ／すべてを太く大きく／なんでも中央揃え／余白を飾りで埋める／背景と同化する文字／同じ構図の使い回し

単体のチェックリストは `ng-checklist.md` にあります。

## 使い方

1. このリポジトリをClaudeのスキルとして読み込ませる（URLを渡す、または `skills/ningen-slides/` をスキルフォルダに置く）
2. 「営業資料を作って」のように普通に頼む
3. スキルがブランド設定を確認し、図解中心で資料を作り、最後にNG点検リストで自己点検してから出す

ブランド設定（メインカラー・書体・ロゴ・会社名・主な出力先）は `brand.example.md` の形で保存でき、次回から確認なしで使われます。
